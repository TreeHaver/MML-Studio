# Project names and visual structure

The header Project field is saved as optional `name` in version-2 JSON. New/unnamed projects display Untitled; imports use their source filename without extension. Renaming is undoable. Save proposes `NAME.json`; filesystem-invalid characters are replaced in the suggested filename, preserving the actual project name.

Draw a silent Instructions marker and select it to edit Time signature and Section. New markers have no explicit tempo, so visual-only markers do not add tempo commands. Existing tempo markers retain their tempo until cleared.

- Time signature is blank to inherit, otherwise e.g. `3/4` or `6/8`. The default is 4/4. Positive whole numerators and denominators 1, 2, 4, 8, 16, 32, 64, 128 are accepted. This is unrelated to permitted musical note durations.
- A signature begins at the marker's exact start, opening a measure there. At an existing boundary, that same measure uses the new signature. An off-boundary change ends the preceding partial measure. Beat and measure lines follow the signature; grid snapping remains the selected note-length aid.
- A nonblank Section names a boundary and appears in the toolbar navigation menu and floating captions below the ruler. Selecting it seeks playing/paused playback, or parks the playhead for the next Play. Stop then Play returns to the selected section. Blank/whitespace names create no section. Conflicting nonblank names/signatures at one time are rejected; identical duplicates are allowed.
- Reset measure count defaults off. When enabled on a named section, its exact start becomes measure 1 and realigns subsequent measures using the active signature. With reset off, the section does not realign or renumber measures. Blank names never reset measures.

These fields (`timeSignature`, `section`, `resetMeasures`) are optional note/event metadata in version 2. Visual rendering reads them only on Instructions lanes. Metadata remains stored if a user changes that lane's preset, and becomes active again when changed back. They do not alter playback or generated MML.

Export > Export sections as separate song sheets applies to selected-instrument and all-instrument export. Every named boundary splits the project independently of its visual reset flag. Music before the first section is retained as Opening. Files include an ordered section prefix; source data remains unchanged. Notes crossing boundaries are clipped and continued in the following segment, with current global tempo and inherited volume restored. Character-limit single/parts choices apply within each segment. Instruments without any sounding note in that segment are silently omitted, including empty and Instructions lanes. No markers means the existing whole-project export behavior.

Core structure math and export slicing: `src/music/structure.ts`. UI ownership: `src/files.ts`, `src/inspector.ts`, `src/toolbar.ts`, `src/export.ts`; grid/ruler renderers use the same measure calculation. Tests: `tests/structure.test.mjs`, `tests/renderer.test.cjs`, `tests/electron-structure.cjs`.

The piano-roll caption displays the current signature, defaulting to 4/4. Click the field to edit at the playhead, or the left visible timeline position when stopped; the position is captured when editing starts. Edits update/create silent Instructions markers and support undo/save without a JSON migration. The display follows global signature changes during playback. MIDI signature events use these same markers (see MIDI_IMPORT.md).

Open Song / Open Segment can now turn the section under the playhead into a temporary editable local timeline. Songs use reset-marked boundaries; Segments use every named boundary. Both generate fresh local MML and character-limit plans, preserve outside note portions when editing, and save changes into the whole project. See SEGMENT_VIEW.md for nesting, history, inherited context and scoped export behavior.

Tempo, section, signature and measure-reset captions are grouped by position into floating bordered text boxes directly below the measure bar. Neighboring boxes stack to avoid collisions, remain pinned vertically while scrolling, and long captions are ellipsized at the viewport edge. The inspector retains their full text. The measure bar contains only measure numbers/lines; yellow tempo lines continue through the roll. Caption rendering belongs to `src/rendering/tempo.ts`.
