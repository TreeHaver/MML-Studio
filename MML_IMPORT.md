# MML import

File > Import MIDI / MML accepts UTF-8 .mml, .ms2mml and .mne in addition to MIDI. Imports replace the project after the existing unsaved-changes prompt. Save Project persists version-2 JSON.

Supported common notation: A–G, +/#/- accidentals, R, N numeric pitches, O and </> octaves, L default lengths (including dots), explicit length denominators, dotted notes/rests, V0–15, positive integer T, & ties, whitespace and // or /* */ comments. Default O4/L4/V8/T120. Plain channels are comma separated; MML@ scores require a terminating semicolon. Unknown commands, macros/loops, invalid ties and conflicting global tempos fail without modifying the project. This is the shared MapleStory/Mabinogi-style MML subset, not every historical MML dialect.

MS2MML accepts the ms2 XML container with melody/chord children, CDATA or escaped text. MNE follows the supplied text format: one named part per MML@ score, with zero-based GM instrument numbers. 3MLE reads Channel sections and TrackName settings; each channel becomes a separate instrument because arbitrary instrument assignments are not yet mapped. MNE ancillary editor settings and 3MLE settings/extensions are reported as unrepresented. No export file-size/channel/note/tempo caps apply.

Durations use 128 units per whole note, independent of the grid. Arbitrary positive denominators are supported; fractional boundaries round cumulatively to nearest integer units with a warning. Durations that round to zero are rejected as a model limitation. Tied continuations merge into held notes; tempos inside held notes/rests use the silent Instructions instrument. Differing simultaneous channel volumes are preserved per note without a conflict warning. Volume changes within ties still have an explicit model-conversion warning and retain the initial onset volume.

Grid paste uses native clipboard events, leaves text fields alone, and parses nonempty text strictly before editing. Recognized MML becomes a selected note group in the active musical instrument at the current paste position; silent tempo events use Instructions. Invalid text leaves data/history unchanged. Internal copy/paste uses a custom clipboard marker and preserves the existing group behavior. Paste supports undo and tempo-conflict validation.

Implementation: src/import/mml.ts (DOM-free), src/files.ts, src/note-clipboard.ts, src/keyboard.ts, main.cjs and index.html. Tests: tests/mml-import.test.mjs and tests/renderer.test.cjs. Native clipboard/dialog testing remains pending. Legacy non-UTF-8 file encodings must be converted to UTF-8 before import.

Confirmed MS2 notation: + and - offset every note letter by one semitone, including E+/B+/C-/F-. # is accepted for importing only and normalized to + in generated MML. GUI labels still use #. Target named-note octaves are O0–O8; B-1 and C9 are emitted as o0c- and o8b+, respectively. Import remains permissive about out-of-target octave/numeric values so source data is retained with export compatibility warnings.
